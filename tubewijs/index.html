Kijklijst

Klaar met kijken? Klik op ✓ Gezien, dan komt de video nooit meer terug in je zoekresultaten.

YouTube-koppeling (gratis)

Gratis aan te maken in 3 minuten: Google Cloud Console → project aanmaken → "YouTube Data API v3" inschakelen → Credentials → API key. Je krijgt 10.000 punten per dag gratis; één zoekopdracht kost 100 punten. Vandaag verbruikt: 0 / 10.000.

AI-hulp (optioneel)

Met AI wordt je vraag vertaald naar meerdere slimme zoekopdrachten (NL + EN) en krijgt elke video een relevantiescore, zodat onzin eruit valt. Gebruikt Claude Haiku: ongeveer €0,002 per zoekvraag, dus je €20 abonnement raak je er niet mee aan (de API wordt apart en per gebruik afgerekend via console.anthropic.com).
